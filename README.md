### About Me

I build backend and AI systems. These days I run [Fergani](https://fergani.tr), where I ship
NextLangua, a language-learning app on the App Store whose speaking practice runs on speech
recognition, LLMs and text-to-speech. Before that I spent nearly three years building
healthcare-education platforms (nhcps.com, savealife.com).

Lately I've been writing small, carefully tested open-source libraries: idempotency and adaptive
load shedding for Go services, a KV-cache manager for LLM inference in C++, and an HNSW vector
index in Rust.

### Interests

LLM inference, real-time audio, distributed systems, and getting software to speak Turkish properly.
